# Apps used in the challenge

| App | What it is | Used in |
|---|---|---|
| [`notes-app`](notes-app/) | A tiny 2-tier web app: Flask + Redis | Week 2 (Docker), Weeks 3–4, Checkpoints 1 and 2 |
| [`error-explainer`](error-explainer/) | A small AI app that explains error messages, with secret redaction, metrics and a free fake-LLM mode | Week 10, Capstone |

Both run with plain `python app.py` first, then in Docker, then on Kubernetes. That's the whole journey of the challenge in miniature.
